# Source logos for the SHOWING view

Drop a logo here to show it for a `showing.entity_id` media player source. The file name is the source name in lowercase, with every run of other characters replaced by `-`:

| HA `source` | File |
|---|---|
| `KPN TV` | `kpn-tv.png` |
| `Pathé Thuis` | `pathe-thuis.png` |
| `HDMI 2` | `hdmi-2.svg` |

`png`, `svg`, `jpg` and `webp` work. A logo here takes precedence over the picture Home Assistant reports.
